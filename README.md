# 💊 MediTrack – Medicine Reminder

MediTrack is a medicine reminder web application designed to help people remember to take their medicines on time, especially elderly people.

## ✨ Features
- Add medicines with name, dosage, and time.
- View scheduled medicines.
- Mark medicines as taken or pending.
- Delete medicines.
- Search for medicines.
- Dashboard to track medicine status.
- Alarm sound and browser notifications.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## 🎯 Objective
To make medicine tracking simple and convenient, helping users manage their medicine schedules.

## 🚀 Future Improvement
- Reminders when the website is closed.
- Online backend hosting.
- Push notifications for scheduled medicines.
